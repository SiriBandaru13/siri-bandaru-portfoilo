# 🛡️ Cybersecurity Portfolio & Security Journal

A personal portfolio showcasing my cybersecurity learning journey, hands-on projects, technical skills, and security research observations.

The portfolio combines a professional profile with a security journal where I explore cybersecurity news, analyze security incidents, and document defensive security takeaways.

🌐 **Live Portfolio:** [siribandaru](https://siribandaru.vercel.app/)
💻 **GitHub:** [SiriBandaru13](https://github.com/SiriBandaru13)

---

## ✨ Features

- **Personal Portfolio** — Introduction, experience, technical skills, and cybersecurity projects.
- **Security Journal** — Curated cybersecurity stories with personal observations and defensive takeaways.
- **Article Detail Pages** — Dedicated pages for individual security stories, including source links and analysis.
- **Responsive Design** — Designed to work across desktop, tablet, and mobile screens.
- **Minimal, Professional UI** — Midnight Plum color palette with a security-journal-inspired aesthetic.
- **Accessibility-conscious Motion** — Respects reduced-motion preferences.

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/SiriBandaru13/siri-bandaru-portfolio.git
   ```

2. Navigate into the project directory:

   ```bash
   cd siri-bandaru-portfolio
   ```

3. Open `index.html` in your browser.

For a more reliable local preview, use a simple development server such as the Live Server extension in Visual Studio Code.

---

## 🌐 Deployment

This portfolio is deployed using [Vercel](https://vercel.com/).

To deploy your own version:

1. Fork or clone this repository.
2. Import the repository into Vercel.
3. Select **Other** as the framework preset.
4. Set the root directory to `./`.
5. Deploy the project.

Vercel can automatically redeploy the website whenever changes are pushed to the connected GitHub repository.
